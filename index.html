救急車が通り過ぎるとき、サイレンの音が「ウ〜↓」と低くなるのを聞いたことがありますか？ この授業では、Adobe Audition の「ドップラーシフター」を使って、音が近づいて、目の前を通って、遠ざかる動きを自分で作ります。Audition が初めてでも大丈夫。上から順番に進めれば、最後には宇宙の環境音と組み合わせた30〜45秒の作品が完成します。你有没有听过救护车经过时，警笛声突然"呜～↓"变低？这节课我们用 Adobe Audition 的「多普勒频移」效果，亲手做出声音靠近 → 从面前经过 → 远去的运动。第一次用 Audition 也没关系，按从上到下的顺序做，最后就能完成一段和宇宙环境音结合的30〜45秒作品。

Adobe Audition（アドビ オーディション）は、Photoshop や Premiere Pro と同じアドビ社が作っている「音」の編集ソフトです。Photoshop が写真、Premiere Pro が動画を編集するように、Audition は録音した声・音楽・効果音を切る、つなぐ、大きさを整える、雑音を消す、響きや動きを加えることができます。Adobe Audition 是和 Photoshop、Premiere Pro 同一家公司（Adobe）出品的"声音"编辑软件。Photoshop 编辑照片，Premiere Pro 编辑视频，而 Audition 可以对录下的人声、音乐、音效进行剪切、拼接、调整音量、去除杂音、加入混响或运动感等处理。

3. しくみ：なぜ音の高さが変わる？3. 原理：为什么音高会变？

音は空気をつたわる波です。波の間隔がせまいと高い音、広いと低い音に聞こえます。
音を出すものがこちらへ向かって動くと、波がぎゅっと詰まって高い音に。遠ざかると、波が引き伸ばされて低い音になります。これが「ドップラー効果」です。救急車のサイレン、踏切を通過する電車、レースカーの「ブーン↓」も、すべて同じしくみです。下のアニメーションで確かめてみよう。声音是在空气中传播的波。波的间隔窄，听起来是高音；间隔宽，就是低音。
发声的东西朝你移动时，波被挤紧，声音变高；远离时，波被拉长，声音变低。这就是"多普勒效应"。救护车警笛、经过道口的电车、赛车的"嗡↓"声，都是同一个原理。用下面的动画确认一下吧。

聞こえる高さ听到的音高 195 Hz ±0

蜂の音（195 Hz）が秒速40 mで、5 m前を左→右に通過。図の波の間隔は見やすいよう誇張しています。数値は実際の計算値です。蜂鸣声（195 Hz）以每秒40米的速度从面前5米处由左向右经过。图中波纹间距为便于观看做了夸张处理，数值是真实计算结果。

（興味がある人へ）計算式（感兴趣的同学看）计算公式
f' = f × c ÷ (c − v·cosθ)
c = 343 m/s (音速 / 声速)
  • 近づく時：v·cosθ がプラス → 分母が小さい → 音が高くなる靠近时：v·cosθ 为正 → 分母变小 → 音变高
  • 真横を通る瞬間：cosθ＝0 → 元の高さ。ここで一気に音程が切り替わる正好经过面前：cosθ＝0 → 回到原音高，音高在这里急转
  • 遠ざかる時：分母が大きい → 音が低くなる远离时：分母变大 → 音变低
  • あわせて「遠い＝小さい・近い＝大きい」、「左→右」の移動も付くので、空間を通り抜ける感じになります。再加上"远＝小声、近＝大声"和"左→右"的移动，就形成了从空间中穿过的感觉。

8. 困ったときは8. 遇到问题时

  • メニューに「ドップラーシフター」がない → マルチトラックの画面になっています。左上の「波形」を押すか、クリップをダブルクリックして波形エディターへ。菜单里没有「多普勒频移」 → 现在是多轨画面。点左上角的「波形」，或双击片段进入波形编辑器。
  • 左右に動かない → ファイルがモノラルかも。右下に「ステレオ」と出ているか確認。ヘッドホンで聴いているかも確認。没有左右移动 → 文件可能是单声道。确认右下角显示「ステレオ」。也确认是否戴着耳机。
  • 音の高さが変わらない → 速度が小さすぎるか、円の中心が自分の位置になっています。速度を上げるか、中心をずらそう。音高没变化 → 速度太小，或圆心在自己的位置。提高速度或移开圆心。
  • ほとんど音がしない → 開始距離が大きすぎて、音が近づく前に終わっています。開始距離を小さくしよう。几乎没声音 → 起始距离太大，声音还没靠近就结束了。把起始距离调小。
  • まちがえて適用した → ⌘Z（command + Z）で1つ前に戻れます。误按了应用 → 按 ⌘Z（command + Z）可以回到上一步。
  • まちがえて ⌘S で上書きした → 「作業用」フォルダーを消して、「01_素材_source」をもう一度複製すればやり直せます。不小心按 ⌘S 覆盖了 → 删掉「作業用」文件夹，再复制一次「01_素材_source」就能重来。
  • それでも解決しないときは、画面のスクリーンショットを撮って先生に見せよう。还是解决不了时，截个图给老师看。
